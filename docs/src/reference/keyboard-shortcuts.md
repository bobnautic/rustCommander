# Keyboard shortcuts

The shortcuts follow the classic commander programs. **F1** shows this list inside the app.
On macOS, **Ctrl** is **⌘**, **Shift** is **⇧** and **Alt** is **⌥**.

## Files

| Key | Action |
|---|---|
| Enter | Open |
| F2 | Rename |
| F3 | View |
| F4 | Edit |
| Shift+F4 | New file |
| F5 | Copy |
| Shift+F5 | Copy without dialog |
| F6 | Move |
| Shift+F6 | Move without dialog |
| F7 | New folder |
| F8 / Delete | Delete |
| Alt+Enter | Properties |
| Ctrl+Shift+C | Copy path |
| Ctrl+K | Compare fingerprints with the other panel |
| Ctrl+P | Open file… |
| Ctrl+U | Upload from this computer (web mode) |

## Navigation and selection

| Key | Action |
|---|---|
| Tab | Switch panel |
| Backspace | Parent folder |
| Alt+← / Alt+→ | Back / forward |
| Ctrl+\\ | Root folder |
| Ctrl+L | Edit the path |
| Ctrl+R / F9 | Refresh |
| Insert | Toggle selection and move down |
| Space | Toggle selection |
| Ctrl+A | Select all |
| Ctrl+Shift+A | Select none |
| + / − | Select / unselect by mask |
| * | Invert selection |
| A–Z | Jump to a file (type-ahead) |
| Esc | Clear the selection, cancel a drag |

## Windows and tools

| Key | Action |
|---|---|
| Ctrl+N | New session (Site Manager) |
| Ctrl+T | Open terminal |
| Ctrl+F | Find files |
| Ctrl+D | Add bookmark |
| Ctrl+Shift+S | Synchronize |
| Ctrl+B | Toggle the sidebar |
| Ctrl+Shift+E | Remote Explorer |
| Ctrl+J | Toggle the dock (queue, terminal, log, search results) |
| Ctrl+H | Show hidden files |
| Ctrl+, | Preferences |
| F1 | Keyboard shortcuts |

## Editor

| Key | Action |
|---|---|
| Ctrl+S | Save |
| Shift+Alt+F | Format document |
| Ctrl+G | Go to line |
| Ctrl+/ | Toggle comment |
| Ctrl+Shift+M | Problems |
| F8 | Next problem |
| Ctrl+= / Ctrl+- | Larger / smaller text |
| Esc | Back to the file panels |

## Remote Explorer

| Key | Action |
|---|---|
| ↑ / ↓ | Move |
| ← / → | Collapse / expand |
| Enter (in the filter field) | Connect to the typed `user@host[:port]` |
| F4 / double-click | Open the file in the editor |
